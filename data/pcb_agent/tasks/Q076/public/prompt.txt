第 076 题 · 在明确约束内设计原理图

你是负责本题的电路工程师，请在本题独立工作目录完成以下任务。

目标
将 USB 主机与 3.3 V 逻辑 UART 设备连接，提供双向串口及 DTR#、RTS# 控制信号。

你的工作
从空工程开始，在公开资源约束内设计原理图，器件与内部连接自主决定。只交付原理图，不要求完成 PCB。

必要要求
- 将 USB 主机与 3.3 V 逻辑 UART 设备连接，提供双向串口及 DTR#、RTS# 控制信号。
- UART 为六针接口，针序：1 GND，2 +3.3 V，3 TXD，4 RXD，5 DTR#，6 RTS#。TXD/RXD 方向以本板为基准；# 表示低有效。
- USB-C 使用 USB2 设备角色；不要求 USB PD 功能。
- 原生网表中独立器件位号总数不超过 17。同位号多单元只计一次；这是题目资源约束，不能以删除必要功能来满足。

本轮公开设计与验收边界
- 题面明确给出的功能、接口及附件优先；未固定的内部拓扑、器件选型和标称设计参数由你选择，并在 design-notes.md 与原理图中明确，使其能被重复核对。对外接口未固定针序时可自行定义并标清；修复题保留输入中的有效接口针号语义，允许有依据地修复损坏连接。
- 采用所声明的标称供电、负载和选定工作模式评估原理图功能；不追加未公开的实物认证、完整设备协议或隐藏阈值。修复题说明输入问题、局部差异与无关电路回归。
- 验收证据由评测侧针对最终交付版本独立产生；生成模型无须交付原生 validation 报告，文件存在不代表功能通过。

输入文件
本题授权的起始文件及阶段以 input-contract.json 为准。
不提供正确原理图、参考 PCB 或内部网表；从空工程开始。

验收条件
- 全部提交主文件可由 KiCad 10.0.6 打开，层级子页与使用到的本地依赖完整。
- 评测侧在最终候选的私有副本上运行全 severity ERC，错误和警告均为零；不得降低规则、隐藏报警或新增豁免。
- 评测侧导出原生 XML 网表，检查本题公开接口、供电与功能要求。开放设计按功能等价验收，不按内部器件编号、网名或文件逐字相等判分。
- XML components/comp 的独立 ref 数量 ≤ 17，并同时满足全部功能。
- USB 通信、UART 双向数据与两个控制信号均应可独立验证；TX/RX 方向以本板为基准。
- USB 端口在全部声明角色、插头方向和供电状态下运行；数据与控制接口分别检验。
- 仅验收本题公开的电路范围与工况，不附加完整设备协议、量产认证、未声明的实物测量或外部系统门槛。

交付内容
- output/ 内的完整工程与依赖：最终原理图、所有子页和必要本地库；影响检查的已有工程配置一并保留。
- design-notes.md：设计依据；修复题补充诊断、改动范围和回归依据。
